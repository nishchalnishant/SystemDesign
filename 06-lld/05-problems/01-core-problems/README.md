# Core Problems (Tier 1)

Solve each of these from scratch at least three times. Between them they cover Singleton, Strategy, State, and Factory — the patterns that carry most LLD interviews.

| File | What it covers |
|------|----------------|

| [Design a Rate Limiter](02-design-rate-limiter.md) | Strategy pattern over token bucket / sliding window. |
| [Design Tic-Tac-Toe](03-design-tic-tac-toe.md) | Clean board modelling and win detection; a warm-up for larger game designs. |
| [Design a Vending Machine](04-design-vending-machine.md) | The State pattern's clearest use case. |
| [Design Splitwise](05-design-splitwise.md) | Expense splitting, balance settlement, and the simplify-debts algorithm. |
