# 5. Interview Templates

This section points to **interview templates** and cheat sheets for system design and low-level design interviews.

## Contents

All template files live in the **[interview-templates](../interview-templates/)** folder:

- **[HLD Template](../interview-templates/hld-template.md)** — Step-by-step high-level design interview guide (45–60 min)
- **[LLD Template](../interview-templates/lld-template.md)** — Low-level design checklist and approach
- **[Capacity Estimation](../interview-templates/capacity-estimation.md)** — Back-of-envelope QPS, storage, bandwidth
- **[Trade-offs Cheat Sheet](../interview-templates/trade-offs-cheat-sheet.md)** — Quick reference for common trade-offs

See also **[SYSTEM_DESIGN_INTERVIEW_FRAMEWORK.md](../SYSTEM_DESIGN_INTERVIEW_FRAMEWORK.md)** at the repo root for how to run the interview (clarify → estimate → HLD → bottlenecks → trade-offs → deep dive → scaling/failure).
